| 2026-10-17 | Setward 1.1 ("training tools") takes the free, offline parts of `FITNESS_APP_IMPLEMENTATION_SPEC_HARDENED.md` plus Hevy-style settings, on branch `training-tools`. Owner choices: local set videos are in (kept on the phone only, never synced or backed up); effort stays RPE on a fixed scale, no RIR field; the Contact page is left out until Google sign-in exists (FEAT-007). Not built, and why: bar-speed sensors, rep detection, velocity metrics, personal RPE models, load prescription from velocity (need a documented device and validation data), coaches, accounts, AI and the server sync API (need a backend or paid services, NN-01 and NN-18), Hevy's Integrations (Health Connect is native-only, Strava needs a server-held secret, ChatGPT sends data out and is paid), Privacy & Social and push notifications (no social features). | The spec itself says no sensor adapter, model or prediction may ship without authorized docs and validation, and the privacy promise forbids new data paths. The offline parts still improve a logger: honest units, safe CSV, a clearer effort scale, equipment-aware warm-ups. | Roadmap "Training tools" |
| 2026-10-17 | SEC-002 / DATA-003 from the spec: CSV cells that start with `=`, `+`, `-`, `@`, a tab or a return get one apostrophe in front when written (`escapeCell`), and `parseSetwardCsv` takes exactly one back off (`unescapeCell`; invertible for text that already starts with apostrophes). The pound is exactly 0.45359237 kg (`KG_PER_LB`), also for Strong imports. | A title like `=HYPERLINK(...)` would run as a formula when a shared export is opened in a spreadsheet. | 2026-10-17 | 1.0 public-launch choices (M7): the link-preview image is a 69 kB JPEG, not a PNG; the site address in the preview tags comes from `SITE_URL` at build time (default: the live site); the privacy policy is a static, English-only page so a store listing can link to it; `LICENSE` names "The Setward authors"; the store route is a Trusted Web Activity, with the Digital Asset Links file served from a free user-site repository, and nothing is submitted. What's new shows once, only to a device that already has data, and a new install just records the version. | Chat apps drop preview images over about 300 kB. The TWA is the free way onto Play, and its fee and testing rules are the owner's decision. A new user is greeted by the welcome screen, so "what's new" would only confuse them. | Roadmap LAUNCH-M7 |
| 2026-10-17 | The ten translations are machine-made and ship as such: the Language page says so and links to report wording. Each is a lazy chunk (precached) except the Arabic font, which loads only for Arabic text and is cached on first use rather than precached. In right-to-left text, number-and-unit strings are wrapped in left-to-right isolate marks at the formatting layer (`isolate()`, no-op in other languages). Translated short words replace long ones where a column is narrow (German "Weiter", `head.reps`, the narrow Previous header). | The owner wants every language free to build and ship now; a native review can follow without code changes because the catalogs are plain data and the test keeps them complete. Precaching a 166 kB font would tax every install for one language. Isolating at the source fixes every screen at once, whereas per-element CSS could not (labels and values share text nodes). Layout limits at 320 px are real constraints, so the word is changed, not the column. | Roadmap LAUNCH-M6 |
| 2026-10-17 | The welcome is one scrolling page of optional sections (language and units, four ways to start, install hint), not a four-step wizard, and Home redirects to it only for an install with no data. Starter programs are routines added in a folder, never started automatically. | The plan's steps were all skippable, so a wizard would only add taps; one page shows everything at once and fits 320 px. A user with data, a running workout or `welcomeSeen` must never meet it. Routines in a folder match how people already organise them and need no new storage. | Roadmap LAUNCH-M5 |
| 2026-10-17 | Settings is a grouped home with one page per section, loaded as its own chunk. "Reset settings" empties the settings record only. The Language page lists all 11 languages from the start. | A single long page was the owner's complaint; sub-pages scale to the catalogue. The Settings code (import, sync, data check) is rarely needed at start-up, so splitting it keeps the main chunk flat. Sync connection and data live elsewhere, so a reset can't lose them. Listing every language now means M6 only adds catalogs. | Roadmap LAUNCH-M4 |
